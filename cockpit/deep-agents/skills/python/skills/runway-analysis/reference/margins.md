# Required Runway Margins

Balanced-field length required at sea level, and the elevation penalty applied
per 1,000 ft of field elevation.

| Aircraft class      | Sea-level balanced field | Penalty per 1,000 ft |
| ------------------- | ------------------------ | -------------------- |
| Light jet           | 3,500 ft                 | 12%                  |
| Mid-size jet        | 4,800 ft                 | 14%                  |
| Super-mid jet       | 5,600 ft                 | 15%                  |
| Regional turboprop  | 4,200 ft                 | 10%                  |

Apply the penalty linearly: a mid-size jet at 7,820 ft needs
4,800 x (1 + 0.14 x 7.82) = 10,055.04 ft (10,055 ft rounded).

Add a further 15% for a wet runway.
