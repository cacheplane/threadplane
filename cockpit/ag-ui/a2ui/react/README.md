# Native React AG-UI A2UI

This private experimental frontend shares the existing AG-UI A2UI Python graph and the closed flight presentation in `libs/cockpit-a2ui-react`. Angular remains the default on the canonical A2UI introduction guide.

Run `npx nx e2e cockpit-ag-ui-a2ui-react` for uncached frozen preparation, one isolated installed-application proof, and the browser suite. Existing Python 3.12 and uv must be available; explicit absolute executable overrides are `THREADPLANE_AGUI_A2UI_PYTHON` and `THREADPLANE_AGUI_A2UI_UV`. `THREADPLANE_AGUI_A2UI_APPLICATION_ROOT` retains all attempted proof consumers, bytes and receipts. Python, caches and HOME are owned outside that uploaded subtree.

The private loopback server buffers actual canonical encoded AG-UI bytes before browser delivery. Each browser conversation owns a separate canonical worker and checkpointer, limited to four real POSTs; generations admit at most eight owners and 32 real POSTs. Reset revokes authority before bounded cleanup, archives receipts and opens fresh routing only after verified closure. Hold/release and explicitly labeled fake negative transport controls exist only in the local proof server. They are excluded from the application bundle and public Code assets.

The browser flow exercises Request, edited Search, Select and server-restored Modify. Native idle state and the original successful run plus matching root completion/transcript are necessary before presentation admission. Stop, error and New synchronously quarantine stale work. Historical form values remain read-only. Positive canonical wire evidence and fake negative transport requests are labeled separately. Local deterministic graph proof does not establish live-provider behavior or full A2UI catalog support.
