# ChatInterruptTemplateDirective

`ChatInterruptTemplateDirective` registers an interrupt renderer on `<chat>`. While the agent has a pending interrupt, the template renders at the end of the transcript, inside the scroll region and after any [run activity](/docs/angular/chat/components/chat-run-activity-template), so approval cards sit in the conversation instead of beside it.

`<chat>` has no default interrupt UI. With no pending interrupt, or no template, nothing renders.

The same template works inside `<chat-popup>` and `<chat-sidebar>`. Both wrappers forward the agent and interrupt context to the inner chat, keeping approval UI inside its scrollable conversation instead of overlaying the composer.

**Selector:** `ng-template[chatInterruptTemplate]`

**Import:**

```typescript
import { ChatInterruptTemplateDirective, type ChatInterruptTemplateContext } from '@threadplane/chat';
```

## Template context

| Variable | Type | Description |
|---|---|---|
| `let-agent` (`$implicit`) | `Agent` | The agent bound to `<chat>`. |
| `let-interrupt="interrupt"` | `AgentInterrupt` | The first pending interrupt, `agent.interrupts()[0]`. |
| `let-interrupts="interrupts"` | `readonly AgentInterrupt[]` | Every interrupt the paused run waits on, in the agent's order. |

The template renders while `agent.interrupts()` lists at least one interrupt. A run continues once, so when it waits on several, answer them together with one `agent.resume(responses)` call. `resume` is an optional command: it is `undefined` on a session that cannot pause.

## Example

```html
<chat [agent]="agent">
  <ng-template chatInterruptTemplate let-agent let-interrupt="interrupt">
    <my-approval-card
      [request]="interrupt.value"
      (decide)="agent.resume?.([{ interruptId: interrupt.id, status: 'resolved', value: $event }])"
    />
  </ng-template>
</chat>
```

[`<chat-interrupt-panel>`](/docs/angular/chat/components/chat-interrupt-panel) works inside the template too:

```html
<chat [agent]="agent">
  <ng-template chatInterruptTemplate let-agent>
    <chat-interrupt-panel [agent]="agent" (action)="onInterruptAction($event)" />
  </ng-template>
</chat>
```

## Accessibility and scrolling

The template renders inside a `role="status"` region with `aria-atomic="false"`, matching the typing indicator, so the arrival of an interrupt is announced. While the transcript is pinned to the bottom, `<chat>` scrolls to keep the region in view as it appears and changes size.
