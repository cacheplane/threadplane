# Custom Catalogs

Both json-render specs and A2UI surfaces render through a `ViewRegistry`. Compose catalogs using `views`, `withViews`, and `withoutViews` from `@threadplane/angular/render`. Pass a json-render catalog to `<chat>` through `[views]`. Pass an A2UI catalog through `[a2ui]`, as `a2uiRenderer({ catalog })` from `@threadplane/angular/a2ui`.

## Using the Built-In A2UI Catalog

`a2uiRenderer()` uses `a2uiBasicCatalog()` when you pass no catalog:

```typescript
import { a2uiRenderer } from '@threadplane/angular/a2ui';

protected readonly a2ui = a2uiRenderer();
```

```html
<chat [agent]="agentRef" [a2ui]="a2ui" />
```

## Adding Custom Components

```typescript
import { withViews } from '@threadplane/angular/render';
import { a2uiBasicCatalog, a2uiRenderer } from '@threadplane/angular/a2ui';

const catalog = withViews(a2uiBasicCatalog(), {
  Chart: MyChartComponent,
  DataGrid: MyDataGridComponent,
});

// in the component class
protected readonly a2ui = a2uiRenderer({ catalog });
```

```html
<chat [agent]="agentRef" [a2ui]="a2ui" />
```

If the page also renders json-render specs with the same components, bind the catalog to `[views]` as well: `<chat [agent]="agentRef" [views]="catalog" [a2ui]="a2ui" />`.

## Overriding Built-In Components

```typescript
import { views } from '@threadplane/angular/render';
import { a2uiBasicCatalog } from '@threadplane/angular/a2ui';

const catalog = views({
  ...a2uiBasicCatalog(),
  Button: MyBrandedButtonComponent,
});
```

## Removing Components

```typescript
import { withoutViews } from '@threadplane/angular/render';
import { a2uiBasicCatalog } from '@threadplane/angular/a2ui';

const catalog = withoutViews(a2uiBasicCatalog(), 'Modal', 'Video');
```

## Custom-Only (No A2UI)

```typescript
import { views } from '@threadplane/angular/render';

const catalog = views({
  Chart: MyChartComponent,
  Table: MyTableComponent,
});
```

```html
<chat [agent]="agentRef" [views]="catalog" />
```

## No Generative UI

If you do not provide `views`, json-render specs do not render. If you do not provide `a2ui`, A2UI content shows as its source text.

```html
<chat [agent]="agentRef" />
```

## Writing a Custom Component

Custom components receive the standard `AngularComponentInputs`:

```typescript
import { Component, input } from '@angular/core';
import type { AngularComponentInputs } from '@threadplane/angular/render';

@Component({
  selector: 'my-chart',
  standalone: true,
  template: `<canvas #chart></canvas>`,
})
export class MyChartComponent {
  readonly data = input<number[]>([]);
  readonly title = input<string>('');
  readonly childKeys = input<string[]>([]);
  readonly spec = input.required<AngularComponentInputs['spec']>();
  readonly emit = input<(event: string) => void>(() => {});
  readonly loading = input<boolean>();
}
```

The component receives resolved props as inputs. `childKeys` and `spec` enable recursive child rendering, and `emit` triggers event handlers defined in the spec's `on` bindings. `Spec` is not exported on its own — type the input via `AngularComponentInputs['spec']` (or implement `AngularComponentInputs` directly).
