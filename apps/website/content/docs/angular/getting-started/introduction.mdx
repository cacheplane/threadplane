# Angular documentation

Start with the Angular guides for agent conversations, streaming, rendering, and backend integrations.

Begin with the [learning workbench](/docs/angular/getting-started/workbench): watch a response stream, inspect a recorded trip conversation, and follow the observations back to the source.

Use the [LangGraph introduction](/docs/angular/langgraph/getting-started/introduction), [installation guide](/docs/angular/langgraph/getting-started/installation), and [quick start](/docs/angular/langgraph/getting-started/quickstart) to connect an Angular application to a LangGraph backend.

Then explore [streaming](/docs/angular/langgraph/guides/streaming), [chat components](/docs/angular/chat/getting-started/introduction), and [rendering](/docs/angular/render/getting-started/introduction). For other backend protocols, read the [AG-UI introduction](/docs/angular/ag-ui/getting-started/introduction).

[Backend middleware](/docs/shared/middleware/getting-started/introduction) is shared across frontend frameworks.
