# React documentation

Explore the experimental React source-build guides, session ownership, and runnable repository examples.

The native React APIs documented here are experimental, private source-build packages. These guides describe repository examples; they are not a public npm installation recipe. Build and run commands appear in the individual guides.

Start with [React streaming](/docs/react/langgraph/guides/streaming) to understand how the application owns a session and React observes its snapshots. Continue with [persistence](/docs/react/langgraph/guides/persistence), [interrupts](/docs/react/langgraph/guides/interrupts), or [client tools](/docs/react/chat/guides/client-tools).

Explore [React render specifications](/docs/react/render/guides/specs) and [React chat messages](/docs/react/chat/concepts/message-model) for presentation. [Backend middleware](/docs/shared/middleware/getting-started/introduction) is shared across frontend frameworks.

The [conversation walkthrough (Angular guide)](/docs/angular/langgraph/concepts/conversation-turns) explains shared concepts and explicitly distinguishes the Angular and private React APIs.
