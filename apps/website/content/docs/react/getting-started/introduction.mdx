# React documentation

Explore the experimental React source-build guides, session ownership, and runnable repository examples.

The native React APIs documented here are experimental, private source-build packages. These guides describe repository examples; they are not a public npm installation recipe. Build and run commands appear in the individual guides.

Begin with the [learning workbench](/docs/react/getting-started/workbench): watch a response stream, inspect a recorded trip conversation, and follow the observations back to the source.

For a source checkout, begin with [LangGraph installation](/docs/react/langgraph/getting-started/installation) and [quickstart](/docs/react/langgraph/getting-started/quickstart). They connect the runnable streaming example to the application-owned session and borrowed React observer. Continue with [persistence](/docs/react/langgraph/guides/persistence), [interrupts](/docs/react/langgraph/guides/interrupts), or [client tools](/docs/react/chat/guides/client-tools).

Use the [chat quickstart](/docs/react/chat/getting-started/quickstart) for transcripts and controls, [AG-UI quickstart](/docs/react/ag-ui/getting-started/quickstart) for native protocol observations, and [Render quickstart](/docs/react/render/getting-started/quickstart) for local interface specifications. [Backend middleware](/docs/shared/middleware/getting-started/introduction) is shared across frontend frameworks.

The [React conversation walkthrough](/docs/react/langgraph/concepts/conversation-turns) connects user turns, requests, tools, UI state, and saved history without changing frontend context.
